# pace lab 🏃

> あなた専用のマラソントレーニング設計室

A personalized marathon training plan generator and tracker.

## Stack

- **Frontend:** React 18 + TypeScript + Vite
- **Backend:** Node.js + Fastify + TypeScript
- **Database:** PostgreSQL + Prisma
- **Auth:** Lucia + Google OAuth
- **Deploy:** Vercel (web) + Railway (api + db)

## Development

\`\`\`bash
pnpm install
pnpm dev
\`\`\`

Web runs at http://localhost:5173, API at http://localhost:3000.

🚧 In active development. Currently: Sprint 1 (foundation).
